┌──────────────────────────────────────────────────────────────────────────────┐
│ ÉTAPE 3: Lancer le script de démarrage AUTO                                  │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  $ bash startup.sh                                                           │
│                                                                              │
│  Le script va:                                                               │
│  ✓ Vérifier Node.js + npm                                                   │
│  ✓ Vérifier .env.local                                                      │
│  ✓ Tester Render Backend (oli-core.onrender.com)                           │
│  ✓ Tester PostgreSQL Database                                               │
│  ✓ Tester Vercel Apps                                                       │
│  ✓ Installer dépendances (si besoin)                                        │
│  ✓ Vérifier migrations DB                                                   │
│  ✓ Proposer de démarrer backend                                             │
│                                                                              │
│  Temps: ~2-3 min (selon vitesse internet)                                    │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

│                                                                              │
│  Taper: y                                                                    │
│                                                                              │
│  Résultat attendu:                                                           │
│  ✓ Server running on http://localhost:5000                                   │
